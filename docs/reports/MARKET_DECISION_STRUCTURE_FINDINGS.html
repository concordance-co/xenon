Market Decision Structure

This report answers one narrower question from the market-manifold research plan: when does the model bind an action-relevant preference to a specific asset? The new 918-tick decision-structure run shows a mixed answer. Buy-side preference is still strongly early, but target-asset and sell-target signals both receive modest downstream sharpening.

March 20, 2026 48 layers Held-out grouped evaluation Supersedes 101-tick pilot
Main read

Not one single stage

The model is not forming all decision structure in one place. The strongest buy-target signal remains in market-row states, while constraints and settings add a small but real lift for target-asset and sell-target prediction. The cleanest interpretation is a staged architecture: early market preference, followed by downstream policy and affordance reweighting.

Method

How the analysis was structured

The report focuses on the decision-structure slice of the broader research plan. We compare what is decodable from market rows alone against what becomes decodable after downstream sections are added.
01

Pool the full sequence

Each captured prompt is reduced into `row_mean_i`, `row_eos_i`, and downstream section states such as `active_settings_eos`, `portfolio_eos`, `constraints_eos`, `prev_decisions_eos`, and `last_token`.

02

Train held-out probes

For each layer, linear probes are trained on grouped splits so row-level labels do not leak across the same decision tick.

03

Compare pre vs post states

Pre states come from the market rows. Post states come from row states concatenated with downstream policy and context sections.

04

Read the staging pattern

If post states beat pre states, downstream context is adding useful structure. If pre states dominate, preference is already formed while the model reads the market.

What changed vs the pilot

The earlier “everything is early” story no longer holds

  • The 101-tick pilot mostly saw early binding because it was small and sell-starved.
  • The 918-tick run preserves the strong early buy signal, but it no longer supports a blanket early-binding claim for every target.
  • Constraints and settings now show a measurable, if modest, lift for some targets.
Narrow conclusion

Decision formation appears staged

  • Market rows already contain a strong candidate preference signal.
  • Downstream context can sharpen that preference when legality, sizing, or actionability matter.
  • The architecture looks more like “early read, later reweighting” than “all policy at the end” or “all preference at the start.”

Interpretation

What this means for the research program

The result slots cleanly into the market-manifold research plan. It gives us the first defensible evidence that the asset-valence manifold is partly present before settings, but not fully identical to the final decision manifold.
Supported now

Early asset preference is real

  • `row_eos` already carries a strong buy-target signal.
  • The model does not need to wait for the end of the prompt to identify an attractive buy candidate.
  • This is the strongest evidence so far for an early asset-valence subspace.
Also supported now

Downstream context is not cosmetic

  • `constraints_eos` improves target-asset prediction.
  • `active_settings_eos` improves sell-target prediction.
  • Policy and legality appear to reweight the early market read rather than simply mirror it.
Best current interpretation: Xenon’s decision structure looks like an early market preference layer followed by a later policy-and-affordance refinement layer. That is exactly the kind of split the research plan anticipated between the asset-in-context manifold, the asset-valence manifold, and the final decision manifold.
Plan Status

What we accomplished and what is still missing

Relative to the root research and implementation plans, this run closes the first serious decision-structure milestone, but it does not finish the broader market-geometry program.
Accomplished

Decision-structure pipeline is now real

  • Balanced cohort selection and full-sequence capture on Modal.
  • Reliable pooled row and downstream section states.
  • Held-out pre/post probe analysis for target-asset, buy-target, and sell-target.
  • A result that now constrains the next research step instead of just validating the pipeline.
Still missing

The manifold program is broader than this report

  • True blocked-bullish and blocked-bearish labels for observe cases.
  • Base market-geometry work: intrinsic dimension, RSA, pairwise probes, router specialization.
  • Stronger settings interventions for clean pre/post reinterpretation tests.
  • Causal necessity tests such as row masking and rank-vs-magnitude corruption.
Next Steps

What should happen after this report

The next move is not another generic capture. The report now gives us enough structure to prioritize the next research step cleanly.
A

Build blocked-valence labels

Use constrained observe examples to separate latent bullishness or bearishness from mere non-action. This is the missing bridge from executed action to the actual asset-valence manifold.

B

Run market geometry in parallel

Start the manifold-side work that does not need new captures: intrinsic dimension, RSA against raw/rank/factor spaces, and router specialization on current row activations.

C

Design stronger settings interventions

Replace weak prompt edits with real policy changes so pre/post reinterpretation can be tested against meaningful shifts rather than near-identity prompts.

D

Only then do causal tests

Once the label program is stronger, run row masking, pairwise swaps, and rank-preserving vs magnitude-preserving corruptions to measure what the model actually needs.
