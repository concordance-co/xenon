# Qwen2.5 MAttr recipe

A completed CPU plumbing fixture for the pinned official MAttr/MIB method on Qwen2.5-0.5B and IOI data. The example uses one seed, two fitting steps and two evaluation examples, with the official ten-point curve.

Qwen follows upstream BF16; GPT-2 follows FP32. Current provenance and configurable workloads are documented in the MAttr guide. This fixture does not establish attribution quality or a cross-model ranking advantage.

Use [the recipe guide](README.md) and `workflow.py` for current execution instructions. Record new experiment outcomes in a new phase rather than extending this fixture’s old run history.
