# SDXL direction preparation

The runnable workflow generates two paired warm/cool discovery images, captures the selected UNet region, derives a bounded warm-minus-cool channel direction remotely and exports the small direction for phase 01.

This is a completed engineering recipe. The larger study in study.py is optional, unexecuted research design; it is not the active workload. Generated images and activations stay on Modal.

Use [the recipe guide](../README.md) and `workflow.py` for current execution instructions. Record new experiment outcomes in a new phase rather than extending this fixture’s old run history.
