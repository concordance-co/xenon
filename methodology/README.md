# Think through a research idea

Use these prompts when they help develop an idea with the user.
They do not require a planning document, a fixed sequence, or checklist completion.

- If you suspect a question beneath the stated question, surface it as a possibility.
  Do not assume the user's framing is wrong.
- Consider approaches that fit the objective. These can include evaluation, prompting,
  data analysis, interpretability, or a combination.
- Treat the user's preferred method as meaningful context.
  Clarify whether it is a requirement only when that distinction changes the work.
- Consider what data would make the question answerable and what is already available.
  Suggest how to fill important gaps instead of asking the user to specify everything.
- Use the available infrastructure to make suggestions practical.
  Check the [capability map](../platform/RESEARCH_HUB.md) and relevant recipe.
- Develop the idea with the user. Add precision where it helps a decision.
  Choose scope from the objective and budget; a simpler design need not be a smaller study.
