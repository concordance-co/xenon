## Required outputs

C01 versioned provenance payload and canonical hash helpers; additive manifest serialization; reuse invalidation tests; documented legacy-reader behavior. Define a separate worker compatibility descriptor consumed by T06.

## Implementation sequence

1. Implement immutable resolved model/tokenizer/component identities, dataset content/row/split hashes, source snapshot (HEAD plus relevant dirty bytes), runtime lock digest, hook/evaluator versions, seeds and effective numerical configuration.
2. Keep requested revisions and resolved commits distinct. Offline execution may use already resolved cache records; unresolved mutable refs are not qualified or reusable as if pinned. Hash all mounted source content affecting computation, not unrelated documentation.
3. Separate scientific identity, artifact content checksum, and worker compatibility. Dtype, attention algorithm, hook semantics, preprocessing, source code, data splits and evaluator affect reuse. Paths, display labels and timestamps do not. Keep hardware/runtime recorded; default to conservative invalidation if equivalence has not been qualified.
4. Add provenance under versioned metadata initially to avoid breaking old manifest constructors. Existing records remain readable, explicitly legacy/unqualified; do not synthesize missing scientific provenance or destroy historical artifacts.
5. Make resolved identity available before selecting reusable artifacts. Model-access tokens and secret values never appear in identity or logs.

## Verification and acceptance

- One-field mutation tests reject stale reuse for model commit, dtype, attention implementation, hook version, data/split, evaluator and source changes; display-only changes preserve scientific identity.
- JSON round-trip and field-order invariance; unsupported future schema rejected with actionable error.
- Legacy records load, but cannot certify a new qualified workload. Existing generation identity behavior remains intact.
- A reference record can explain why two runs did/did not reuse outputs without relying on file paths.
