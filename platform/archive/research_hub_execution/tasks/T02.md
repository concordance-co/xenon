## Implementation sequence

1. Extend ExecutionPlan compatibly with structured check results: phase, check_id, status, field, explanation, remediation, evidence. Separate static validation, environment readiness, and measured qualification; `unknown` is not `passed`.
2. Static checks validate unknown keys, finite positive sizes, dtype/device support, context/output budget, token/capture shape, model-parallel GPUs versus independent shards, host RAM, mounts, secret binding names and store/catalog intent. Static checks include operator-support validation: each engine declares its supported patch operator set, and a PatchedGenerationSpec whose operator is outside the bound engine's set fails at plan. Planning must not allocate GPUs; offline plan labels inaccessible metadata unresolved.
3. Extend PythonRuntimeSpec with a lock descriptor and runtime identity. Resolve transitive pins separately for local OS/architecture and Linux/CUDA, including Python/base image/CUDA requirements. Build from lock bytes, not loose constraints layered on unconstrained pip installs. Preserve legacy pip_packages inputs as unqualified compatibility mode. Audit every `runtime_spec()` wrapper and `_resolved_runtime_spec_many` merge: capture/generation/patched specs currently reconstruct PythonRuntimeSpec field by field. Preserve lock/build descriptors through these wrappers (with round-trip tests), reject incompatible lock merges and never silently drop the new fields.
4. Run import/access/cache/checkpoint completeness/source packaging/dataset schema/store readiness before weight load where feasible. Never assert remote access was checked just because a secret name was declared. Retry transport failures only under an explicit small bound.
5. Separate scientific capability from device qualification. Emit the effective config and override origins with secrets redacted. New profile changes flow to T06 instead of quietly borrowing a similar profile.
6. Supply the C01 facts that T01 deliberately leaves unresolved. Bind admitted immutable model/tokenizer/component and runtime observations to both caller reuse selection and worker validation; never substitute caller-installed packages for worker facts. Own numerical-policy resolution for the existing supported CPU analysis operations (including probes, directions, bases, centroids and geometry): record effective algorithm/backend, dtype, declared numerical environment, determinism and explicit seed/RNG policy, using operation-specific resolvers. Restore ordinary workflow resume/reuse only when these facts are complete. Unsupported or unseeded stochastic operations remain unresolved with an actionable diagnostic; do not mark generic operation-defined placeholders as observed. T05 consumes these complete identities for safe checkpoint recovery.

## Verification and acceptance

- Parametrized wrong-GPU/count, negative/NaN RAM, typo, unsupported hook/dtype, bad path, missing model revision and missing lock cases never invoke mocked Modal submission.
- A clean environment installs each initial lock and imports its declared modules. vLLM and research stacks are never imported together as a validation shortcut.
- Readiness reports missing access, incomplete cache and incompatible imports before weight initialization. Existing valid workflows still serialize/plan.
- Real supported CPU analysis workflows resume/reuse under their production policy resolvers without test-only provenance injection; changing algorithm, seed, dtype, numerical environment or upstream identity invalidates reuse. Unknown stochastic policy stays unresolved. A worker rejects admission observations that disagree with the actual mounted source/runtime/components.
- Rebuilding same lock reproduces package inventory; changing its bytes invalidates image/profile identity. GPU binary compatibility is qualified live later, not declared by CPU import.

New `tests/pipelines_v2/runtime/test_admission.py` and `test_runtime_locks.py`; existing `test_preflight.py`, config, deployments and runtime contract tests. Lock checks use fresh environments, with exact commands saved.
