## Required outputs

C05 pack/evidence schemas, helper validation, `workspaces/` conventions, minimal report components for provenance, controls, verdicts and diagnostics. Template only; actual studies instantiate their own PHASE and workflow.

## Implementation sequence

1. Define pack metadata referencing one workflow.py, source/model/data locks, question/hypothesis IDs, presets, limits, split rules, metrics/controls, admission requirements and expected outputs. Presets build existing WorkflowSpecs, not a parallel workflow language.
2. Separate setup, smoke, reference and scale. A smoke fixture is not a paper result; a reference run must state which paper settings match. Scale is disabled unless its finite resource envelope and upstream qualification are present.
3. Use existing phase/hypothesis lifecycle. Initialize only Premise/Artifacts before experiments; populate results and claim boundaries from actual evidence. Record engineering status separately from scientific verdict: supported/refuted/inconclusive/not-tested.
4. Reports take explicit direct inputs and render locally. Add `.gitignore` entries for `workspaces/**/reports/**/report_*/` and each supported workspace artifact root; tensor extensions are already globally ignored. Add capped result summaries and evidence links to examples/artifacts; do not fetch bulk captures. Validate links refer to immutable IDs and selectors.
5. Add helpers for named preset selection through an environment variable read by workflow.py (`XENON_EXPERIMENT_PRESET`, default smoke) until a first-class CLI option is justified. Preserve workflow plan/run/runs/show/resume commands and FileCatalog indexing.

## Verification and acceptance

- Pack validates with one executable workflow source and consistent version hashes; malformed split/metric/control/budget metadata fails before running.
- Toy pack plans/runs/reports through existing CLI; a fresh process locates it through the catalog and reproduces result provenance.
- A deliberately negative scientific result renders as a valid completed experiment with refuted/inconclusive verdict, not failed plumbing.
- Missing evidence links and excessive report payloads are rejected; reports do not trigger remote tensor downloads.

New `tests/pipelines_v2/workflow/test_experiment_packs.py` and `tests/pipelines_v2/reporting/test_evidence_reports.py`; existing workflow/report tests.
