## Implementation sequence

1. Prepare a pinned `openai-community/gpt2` snapshot and tokenizer in a separate explicit download step; verify exact resolved hash and cache completeness. Workflow execution itself is offline. A tiny random model tests code but cannot replace this pretrained proof.
2. Freeze eight short matched prompts (<=128 input tokens, <=16 generated tokens), donor/recipient keys and one residual site. Establish baseline behavior before claiming an intervention target. Track a predeclared token/logit contrast even if free generation is not useful.
3. Run baseline capture, identity (`ScalePatch` 1.0), zero (`ScalePatch` 0.0), and independently verified full-state donor replacement (`InterchangePatch`). Build same-label and seeded random-donor controls as explicit paired `InterchangePatch` cases via `pair_by`, not nonexistent patch kinds. Choose single-token targets under the pinned tokenizer for T04 target-logprob contrasts. Report intended/reverse effect and malformed outputs; distinguish tensor correctness from scientific effect.
4. Produce local provenance/control/results report through ReportSpec; split preparation/download/cold-load/warm execution timings. Target warm experiment <60 seconds on the recorded host. An honest performance miss is diagnosed, not hidden with a toy replacement.
5. Repeat in a fresh process with credentials unset and network/cloud sentinels. Interrupt after an output unit and resume to exactly the same coverage. Show workflow runs/show discovery and exact rerun command.
