## Implementation sequence

1. Build bounded top/bottom-k, distribution histograms/quantiles, random and weak-activation reservoir samples. Keep raw values and percentile context; preserve original text/token windows with data references. Streaming results must not depend on batch order beyond documented sampling seeds.
2. Freeze the initial pilot at 24 neurons sampled uniformly within six depth strata (four each), a pinned [Salesforce/wikitext](https://huggingface.co/datasets/Salesforce/wikitext) `wikitext-103-raw-v1` snapshot with disjoint document train/held-out partitions (reconstruct article boundaries before sampling; do not split neighboring paragraph rows across sets), and short/long context strata. Record dataset terms/source and a repeatable bounded importer: shared text/labels in Neon, captures in Modal; local fixture subset only under T03. Reference expands only after budget and behavior qualification; keep sample weights explicit.
3. Compare product-only and gate/value/sign-aware explanation views. Version explanation prompts/providers; local smoke uses stored/manual candidate descriptions and no API judge. Blind held-out positive/near-miss/distant examples and a shuffled-explanation control; explanations never see held-out examples during creation.
4. Test weak-activation removal against count-matched and activation-magnitude/norm-matched controls on preregistered behavioral metrics; retain rare and unexplained cases. Same-label/random/identity edits report target and collateral effects. Produce bootstrap intervals at document/template sampling unit, not neuron-token pseudoreplication.
5. Run 0.6B tooling pilot, then independently qualify 32B with its memory profile before study. Freeze thinking mode/template/tokenizer and all resolved versions. Record conceptual replication, not exact reproduction of unavailable Goodfire custom checkpoints. Link task-relevant MAttr rankings only after T11/C06 provenance is available; this optional cross-paper join is not a prerequisite for the microscope.
