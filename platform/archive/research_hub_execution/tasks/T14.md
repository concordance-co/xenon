## Required outputs

C07 graph/result schema, native candidate-route builder, C06 MAttr node annotation importer, original-model intervention evaluator, bounded graph report; cross-paper neuron-ranking join.

## Implementation sequence

1. Define stable nodes and typed edges plus target output, algorithm/version, site identities, score units, approximation assumptions, pruning rule and omitted/error contributions where defined. Enforce that MAttr scores annotate rankings and are not labeled additive causal edge weights.
2. First native builder uses a selected small set of sites and measured direct patch/path effects. Add native input-times-gradient and integrated-gradient candidate ranking on T04 differentiable forwards, with explicit scalar target, baseline and integration grid. Check gradients/IG on analytical fixtures and compare selected candidates with direct interventions; approximations are not causal proof. Treat route proposal separately from causal validation; no claim that an arbitrary graph view discovers a complete circuit.
3. Implement original-model route tests with matched donor pairs, identity, same-label, random/resampled and zero controls as appropriate. Hold out task templates. Log read-versus-write site distinctions and intervention scope.
4. Join MAttr node IDs to C04 neurons only through a verified explicit basis mapping. Refuse unsupported mapping; include upstream model-loading transforms, normalization/centering and site semantics, and verify matched tensor values before joining. Do not assume TransformerLens and HF coordinates align by name.
5. Build a small local graph report with node/edge inspection and links to bounded examples/effect tables; cap nodes/edges and retain omitted counts. C07 is also the future T20 importer contract.

## Verification and acceptance

- Schema rejects missing provenance, inconsistent site IDs, unknown semantics and ranking-as-flow; round-trip keeps approximation/error metadata.
- Analytical toy graph and intervention fixtures recover the known effect under independent forward checks; negative control graphs are not labeled validated.
- One real task graph links to a held-out original-model intervention report; report rejected routes explicitly.
- Node annotation joins preserve coverage and identify unmatched nodes; layout never alters scientific scores. Report does not load full activation banks.

New `tests/pipelines_v2/operations/test_attribution_graphs.py`, `test_graph_interventions.py`; a bounded real route-validation workflow is required.
