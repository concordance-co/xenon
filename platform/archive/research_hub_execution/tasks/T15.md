## Required outputs

Image-input/preprocessing and spatial C04 coordinates, one torchvision ResNet-18 adapter with pinned weights, natural-example/visualization pack and spatial intervention oracles. This is independent of the SDXL generation path.

## Implementation sequence

1. Freeze torchvision ResNet-18 weight revision, preprocessing resize/crop/normalization and class map. Use a seeded <=64-image subset of [Oxford-IIIT Pet](https://www.robots.ox.ac.uk/~vgg/data/pets/) through its documented download/annotation manifest; record source terms and archive hashes. Separate image IDs between discovery and held-out evaluation. Store image bytes in the durable image store and shared metadata/labels through the existing dataset/catalog conventions. Input manifests include content hashes; image bytes live in artifact stores.
2. Expose a selected convolutional channel pre/post activation at a known layer; define batch/channel/y/x layout and receptive-field mapping. Record input versus preprocessed pixel coordinates and interpolation.
3. Retrieve natural high/low/random image patches, then implement bounded input optimization for feature visualization with declared regularization and multiple seeds. Do not treat optimized pictures as explanations by themselves.
4. Test the proposed feature on held-out natural examples and controlled crops/occlusions; compare shuffled channel/control images. Verify pixel and internal channel interventions independently.
5. Render capped local galleries linking every crop to original input/preprocess/site. Use shared image artifacts with T16 where compatible without requiring the same engine or classifier/generator semantics.
