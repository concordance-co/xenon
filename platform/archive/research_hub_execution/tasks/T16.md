## Required outputs

Optional `engine/diffusers/` runtime, SDXL generation/capture/intervention operations, exact component/preprocessing/scheduler identities, C08 image/latent artifacts and a measured Modal qualification.

## Implementation sequence

1. Resolve `stabilityai/stable-diffusion-xl-base-1.0` and all text encoder/UNet/VAE/tokenizer/scheduler components to exact versions. Build a separate Diffusers lock/image through T02; record model license and existing access requirements. Use the mounted model cache.
2. Define denoising step index and scheduler timestep separately; support module-output capture, direction addition, ablation and matched activation replacement. Validate full tensor axes against actual module outputs before running. A pipeline step callback alone does not implement an internal hook.
3. Verify CFG layout for conditional/unconditional concatenation; branch selector must affect the intended half, including CFG disabled, different batch sizes and prompt-negative-prompt alignment. Reject unsupported layouts, offload/compile modes or scheduler combinations.
4. Persist initial latent/noise content hash, generator state, prompt embeddings identity and scheduler config. Fixed noise is a shared input to baseline and edits, not separately seeded random generation that may consume RNG differently.
5. Use image-boundary recovery initially. Mid-trajectory checkpoints are accepted only if scheduler history, step/RNG and latent state have an executed replay oracle. Session reuse resets scheduler/hook/generator state between images and records loads.

## Verification and acceptance

- Tiny deterministic UNet fixtures prove site/step/spatial/branch selection and unchanged unselected tensor cells; no-op and original-value replacement match direct pipeline baseline.
- One real SDXL baseline/capture/edit proves hooks fire on expected shapes and edits reach downstream computation. Fixed-noise no-op uses a declared repeatability tolerance; do not promise cross-device pixel identity.
- All component/scheduler/preprocessing changes invalidate identity. Wrong branch/site/checkpoint fails before expensive trajectory.
- Interrupt between images and resume without duplicate/missing keys; no final manifest for an incomplete image set. Record memory/loading peaks on the actual selected GPU.
