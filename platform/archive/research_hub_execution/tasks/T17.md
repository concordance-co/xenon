## Implementation sequence

1. Select a simple measurable first target: warm versus cool background color while preserving a fixed foreground object description. Freeze 8 direction-discovery prompt pairs and 8 held-out object/prompt templates, with two held-out noise seeds each. Disjoint prompt families prevent identical wording leakage.
2. Fit one activation direction from discovery pairs at one qualified site/step window. Save training input identities, normalization and scope. Freeze strength values 0, 0.5, 1, 2 times a documented activation-RMS scale before held-out evaluation.
3. For every held-out prompt/seed, reuse identical initial noise across baseline, zero-strength/no-op, intended direction and norm-matched random-direction controls. Limit to preselected site/step settings; exploratory retuning creates a new phase and split.
4. Use a pinned pixel-color/background-region metric as primary attribute measure; use a separately pinned segmentation pipeline if available and validated on discovery images, otherwise preregister a fixed mask excluding the central 50% width/height crop and measure mean warm-versus-cool color over the remaining region. Label this as a background-color proxy with foreground/spatial blind spots; validate on controlled synthetic image changes, and use blinded human annotations only if actually available. Record foreground preservation, prompt adherence and image degradation with distinct measures; no single CLIP score stands in for quality.
5. Report paired effect sizes and uncertainty at prompt level, controls, failures and full capped gallery. If a human annotation panel is unavailable, export blinded sheets, label automated metric limitations and do not claim human-perceived quality. Null steering results are scientifically valid, while the end-to-end capability still requires demonstrated tensor intervention.
