## Required outputs

Dictionary import/encode/decode specs and artifacts, SAELens isolated dependency adapter, checkpoint/model/site verification, feature splice intervention and fidelity report for a GPT-2 residual dictionary.

## Implementation sequence

1. Inspect official SAELens release metadata; start with release `gpt2-small-res-jb`, SAE ID `blocks.6.hook_resid_pre`, repository `jbloom/GPT2-Small-SAEs-Reformatted` from the [official GPT-2 catalog](https://decoderesearch.github.io/SAELens/latest/pretrained_saes/gpt2-small/). Pin actual weights and verify exact checkpoint/site/token-normalization compatibility; this is a candidate, not assumed qualification. Freeze release, checkpoint hash, architecture, activation function, normalization and decoder conventions. If none matches, record the blocking mismatch; do not relabel a different model's dictionary.
2. Convert through a versioned adapter retaining encoder/decoder/bias and any required preprocessing. Use a dedicated optional lock or process if incompatible with the Torch engine. Record model-loading transformations (including any TransformerLens layernorm folding, weight centering and bias conventions). Prove the mapping from the dictionary training coordinates to the HF hook with paired tensor/encode oracles; if it cannot be established, qualify another documented GPT-2 residual release rather than applying a mismatched dictionary. An isolated upstream reference may supply the oracle but does not replace the required original-model splice. Tensor IO must not require unsafe arbitrary pickle loading from untrusted sources.
3. Implement encode/decode, sparse activation summaries and interventions at the qualified original-model site. For feature editing, explicitly choose reconstruct-only versus original plus decoded feature delta; record residual error and baseline differences for each.
4. Measure reconstruction MSE/normalized error, sparsity, explained variance where meaningful, original versus reconstruction logits/task behavior, and feature causal effects versus random/PCA/native controls under matched budget.
5. Ensure hooks restore original activations when no-op is intended; reconstruction replacement is not intrinsically no-op. Produce a small report with dictionary coverage and fidelity limitations.
