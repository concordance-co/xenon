## Required outputs

Crosscoder import/fit/encode/decode operations, paired-activation alignment record, resumable fitting worker, one bounded Qwen2.5-0.5B base/instruct pack and causal report.

## Implementation sequence

1. Resolve public `Qwen/Qwen2.5-0.5B` and `Qwen/Qwen2.5-0.5B-Instruct` checkpoints and qualify exact adapter behavior. Add the narrow Qwen2.5 dense adapter needed for this pair, since T12 qualifies Qwen3/GPT-2 only; prove direct-forward/capture/patch parity for both checkpoints before fitting. Verify architecture, tokenizer and residual-layer compatibility; choose one matched layer and identical tokenized inputs. Shared raw text with different templates is not aligned-token evidence.
2. Capture paired activations with explicit example/token indices and model-side identity; reject missing/duplicate/misaligned positions. Split by document/prompt family before fitting.
3. Integrate a pinned crosscoder reference implementation in an isolated fitting runtime. Configure small dictionary width, optimizer, sparsity loss, batch schedule and seeds before training. Save weights, optimizer, sampler position, schedule and CPU/CUDA RNG state with C03 checkpoints.
4. Fit one bounded dictionary and compare model-specific feature activation/reconstruction behavior. Select a hypothesis on discovery split, then intervene on decoded directions in each original model with matched-norm/random/same-label controls.
5. Report reconstruction, feature stability across at least two small fitting seeds, held-out target and collateral effects. Decoder norm asymmetry only proposes a candidate; it cannot by itself establish a model difference or causal role.

## Verification and acceptance

- Synthetic paired-data oracle recovers alignment and detects swapped rows, tokenization differences and model order changes.
- Paused/resumed tiny deterministic fit matches uninterrupted loss/weights under declared tolerance; corrupt/foreign checkpoint rejected.
- Both base/instruct direct-forward adapters pass, reconstruction effects are measured separately, and a real held-out intervention tests one hypothesis.
- Null/unstable feature findings remain visible. No arbitrary cross-architecture neuron correspondence is used.

New `tests/pipelines_v2/operations/test_crosscoder.py`, alignment/checkpoint oracles and bounded real pair study.

## Resource and external dependency limits

One layer, dictionary width <=2048, <=100k aligned token pairs, <=2000 optimizer steps/seed, two seeds, <=2 GPU-hour initial cap. Exact feasible batch chosen by backward canary; a cap hit leaves fit incomplete.

A required inaccessible asset or unexecuted live gate leaves the task integration-pending. Complete independent implementation and deterministic tests, retain diagnostics, and name the exact remaining gate. Do not silently substitute a different model/evaluator or mark fixture tests as live qualification.

## Outside this task

No cross-layer transcoder substitution, large crosscoder campaign, finetuning in core or claims from decoder norms alone.
