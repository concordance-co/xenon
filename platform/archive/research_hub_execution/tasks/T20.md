## Required outputs

Isolated pinned circuit-tracer adapter, compatibility manifest for one accessible supported pair, C07 graph importer with error contributions and original-model validation pack.

## Implementation sequence

1. Inspect official circuit-tracer supported release metadata. Start with the documented Qwen3-0.6B pair and `mwhanna/qwen3-0.6b-transcoders-lowl0` listed by the [official tool](https://github.com/decoderesearch/circuit-tracer); these are per-layer transcoders (PLTs), not CLTs. Preserve `dictionary_type` and source/destination layer maps. CLT-format import also needs a fixture; live CLT support remains unverified until a separately accessible CLT pair is run. Verify current upstream support and access rather than assuming the listing proves them; freeze exact model/transcoder/tool commits. If the selected model/pair requires existing gated access, bind HF_TOKEN and verify access/license state during readiness; do not accept new terms on the user's behalf. If no accessible supported pair exists, preserve adapter fixture implementation and record the exact asset/access blocker; never manufacture a pair.
2. Reuse external-tool execution and cancellation mechanics from T10, but maintain a separate lock and runtime. Validate checkpoint/site/tokenizer identity before trace computation.
3. Import replacement-model nodes/edges, signed weights, target, attention/normalization assumptions, pruning threshold and all residual/error contributions defined upstream. Scores retain upstream units and graph semantics.
4. Measure replacement fidelity on a held-out task slice, trace a small selected prompt set and propose one route. Test relevant features/routes in the original model with identity and matched controls. Label inability to map a route back as unvalidated.
5. Render alongside native graphs through C07 without suggesting identical edge meanings. Save raw upstream artifacts and a reversible ID mapping for audit.

## Verification and acceptance

- Pinned upstream PLT and CLT graph fixtures round-trip with no dropped error nodes/edges or sign changes; unknown schema rejected.
- Wrong model/transcoder pair fails admission; live qualified pair builds and emits a graph reproducibly within tolerance.
- Replacement fidelity and original-model route-test results appear together. A route that fails validation remains a rejected candidate.
- If weights are inaccessible, task is integration-pending; fixture tests alone do not satisfy the pair qualification gate.

New `tests/pipelines_v2/operations/test_circuit_tracer_import.py`; external process tests reused; actual pair qualification and original-model validation evidence required.

## Resource and external dependency limits

One supported pair, <=8 tracing prompts and <=16 validation pairs, initial <=1 GPU-hour cap after <=2 bounded canary attempts. Tracing shape must be qualified separately from inference.

A required inaccessible asset or unexecuted live gate leaves the task integration-pending. Complete independent implementation and deterministic tests, retain diagnostics, and name the exact remaining gate. Do not silently substitute a different model/evaluator or mark fixture tests as live qualification.
