## Required outputs

Import-light `pipelines_v2/evidence/` public query layer, CLI evidence/compare commands, neuron/graph/gallery report panels, compatibility-aware comparison matrix and capability/failure views. Optional UI package consumes the same API.

## Implementation sequence

1. Query existing catalogs for runs/artifacts, then resolve C05 evidence references and capped summaries. Do not create a parallel index/database. Keep query API independent of CLI private functions and optional dashboard dependencies.
2. Implement discovery by study/model/operation/status, comparison by explicit metric/split/evaluator identity and provenance diff. Incompatible results are visible as non-comparable; never average different evaluation definitions.
3. Add report panels for neuron dossiers, typed graphs and paired image galleries using fixtures first. Every scientific claim links to underlying examples and intervention evidence; expose unresolved, partial, legacy and unqualified states.
4. Show exact replay command/config and source/runtime requirements; unknown missing assets produce explicit readiness diagnostics. Opening a report does not run an experiment or download bulk tensors.
5. Keep initial UI delivery to local report navigation and compact interactive viewers where useful. Existing dashboard is excluded from public package; any optional UI wiring must not become a core dependency or broaden into a redesign.

## Verification and acceptance

- Fresh process with only catalog and referenced summaries discovers and renders selected local/published runs.
- Mock remote store fails any bulk activation request; report browsing still works within payload cap.
- Mixed evaluator, split, tokenizer/hook or graph semantics cannot be silently compared as equivalent.
- Demonstrate one dossier, one graph and one steering gallery from actual upstream task artifacts; fixture-only panels remain integration-pending.
- CLI/Python core imports without torch/Diffusers/UI stack; query failures never mutate runs.

New `tests/pipelines_v2/evidence/test_queries.py` and `test_comparison.py`; report rendering smoke and CLI help/round-trip tests. The independent reviewer model opens rendered reports and attaches a short description of each panel to the receipt; human inspection is optional and not an acceptance condition.

## Resource and external dependency limits

Report cap defaults 100 examples, 100 graph nodes/300 edges, 32 gallery images and 16 MiB transferred summaries per view. Pagination explicit.

A required inaccessible asset or unexecuted live gate leaves the task integration-pending. Complete independent implementation and deterministic tests, retain diagnostics, and name the exact remaining gate. Do not silently substitute a different model/evaluator or mark fixture tests as live qualification.

## Outside this task

No hosted multiuser product, dashboard redesign, new database, agent chat orchestration or automatic experiment launches.
