## Required outputs

Isolated official parameter-attribution adapter, exact parameter mapping validation, benign checkpoint-pair provenance, bounded row-mask fitting and target/collateral evaluation pack. Conditional follow-on, outside first release.

## Implementation sequence

1. Prefer the official parameter-attribution repository's documented spelling/case checkpoint pair and task. Resolve exact source/target checkpoints, training provenance and evaluator. If these are unavailable, require a sibling-produced benign task-specific finetune with exported training/data metadata; a generic base/instruct pair is not silently relabeled as a spelling change.
2. Verify identical parameter names, shapes, dtype conversion policy, tied-weight handling and architecture. Compute delta identity and exact reconstruction of endpoint checkpoints. Quantized/merged adapter mappings require explicit validation or are unsupported.
3. Reuse official mask-learning semantics in its own runtime; freeze what rows/tensors are mask units, baseline/source orientation, sparsity grid, loss, optimization budget and evaluation splits. Persist optimizer/sampler/RNG when supported.
4. Compare top-ranked, random, magnitude and appropriate gradient baselines across sparsity, measuring held-out target loss/behavior and unrelated task regressions. Validate selected masks directly in original models.
5. Report endpoint checks and both recovered behavior and collateral effects. A failure to find a compact set is a legitimate result; no fixed top-1-percent recovery threshold is assumed.
