## Required outputs

C08 image-input and latent records, shared spatial/timestep selectors, registered tensor/image codecs and deterministic sharding identity; fixtures consumed by T15 and T16.

## Implementation sequence

1. Add image inputs as an explicit compatible data type, not image bytes stuffed into Example.prompt. Preserve legacy text Example serialization and prompt hashes; define resolved execution-key identity including text, image content hashes, preprocessing and ordering.
2. Route new image examples through dataset resolution and shard assignment using that identity. Expose shard identity as a pure function consumed by the existing shard helper; do not restructure remote_executor beyond that call. Same bytes under a different path remain the same input; changed bytes at the same path change identity. No URI-only content identity.
3. Define image format/color space/range/layout, latent tensor dtype/shape, preprocessing/component hashes and origin refs. Persist tensor payloads through registered formats; separate thumbnail summaries from full payloads.
4. Specify spatial coordinate basis, mask interpolation, channel axis, timestep index versus scheduler value and CFG branch enum. Recognition consumes spatial fields only; diffusion adds trajectory/branch semantics. Invalid mixed coordinate requests fail early.
5. Implement bounded, validated input preparation with content hashes and cache refs; no arbitrary URL fetch during offline execution. Document locality for this new class: shared image bytes/latents in Modal volumes, shared image metadata/labels in Neon, bounded local fixture images under T03. Sharing artifacts does not imply that classifier and generator use the same normalization.

## Verification and acceptance

- Text legacy hashes unchanged; image content/order/preprocessing changes affect new identities and shard mapping deterministically.
- Image/latent codecs round-trip values and metadata without JSON tensor expansion; malformed layouts/ranges/coordinate masks rejected.
- Known synthetic image/spatial-mask fixtures verify pixel-to-preprocessed coordinates; latent timestep/CFG fields serialize with exact meanings.
- Local/fake remote input resolution respects transfer and offline policies; summaries never localize a full activation bank.

New `tests/pipelines_v2/data/test_image_inputs.py` and `tests/pipelines_v2/storage/test_image_artifacts.py`; legacy text dataset and shard tests.
