# Phase 04 Entry Criteria

Promote a label family to causal follow-up only if:

- generation quality gate has passed with manual inspection
- label definitions are frozen on the actual row universe
- activation readout beats the named text baseline
- grouped split performance remains above baseline
- localization identifies a meaningful token/span/layer band
- same-label and shortcut controls are planned for the intervention
