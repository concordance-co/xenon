# Prompt Confusion Phase 04 -- Index

Phase 04 is a methodological reset of the prompt-confusion benchmark:
smaller dataset (288 rows), explicit STRATEGY vs SETTINGS roles, neutral
phrasing, prompt-only capture. The goal is to determine whether a language
model builds internal representations of instructional conflict and, if so,
how it resolves that conflict.

Model: `Qwen/Qwen3-30B-A3B` on Modal (vLLM). Capture: residual stream +
router logits, prompt-EOS pooling, 12 layers.

## Key Findings

1. **Conflict detection is strong.** 92% balanced accuracy at layer 36 on the full 288-row dataset. The model clearly represents whether its instructions conflict.

2. **The model can be causally steered.** Injecting the SETTINGS direction at layer 24 moves behavior: `strategy_push` shifts +9pp toward strategy-following, `setting_push` shifts +3pp toward setting-following.

3. **Arbitration is real but confounded.** The conflict-side label (which side wins) is predictable at 80% from just `strategy_family + pressure_bucket` -- better than the best residual probe (71%). The model resolves conflicts family-specifically, not via a single generic arbitration circuit.

4. **Attention is not yet informative.** Section-aggregated attention mass barely beats chance as an arbitration decoder (best: 59%).

5. **The confound is structural, not trivial.** Token length alone does *not* explain the label (`length_position_numeric` = 49%). The confound is family semantics and pressure structure.

## Open Questions

From the [Stage 2 handoff](reports/PHASE_04_STAGE2_HANDOFF.md):

- **Family-controlled arbitration** is the next high-value analysis: within-family probes, or regressing out family/pressure before probing, to test whether the causal effect reflects a cross-family arbitration feature or just family-specific structure.
- Whether the causal asymmetry (strategy_push >> setting_push) is a property of the model or the dataset.
- Whether scaling to more families / more rows changes the confound picture.
