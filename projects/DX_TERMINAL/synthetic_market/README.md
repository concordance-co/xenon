# Synthetic Market

This subproject holds the synthetic-market research program inside
`DX_TERMINAL`.

Layout:

- `shared/`
  Shared synthetic-market analysis code and experiment runners used across
  multiple phases.
- `dimension_exploration/`
  Discovery, representation, and early decomposition deliverables.
- `restoration/`
  Source-driven restoration experiments and reports.
- `path_validation/`
  Lesion-and-rescue validation work.
- `reports/`
  Subproject-level external/public-facing reports.

Reusable synthetic dataset builders remain under `pipelines/interp/synthetic/`.
